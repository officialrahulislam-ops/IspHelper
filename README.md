# WiFi Pulse

An aesthetic, modern WiFi analysis tool built with Flutter.

## Features
- Connected WiFi Name & IP Detection
- Signal Strength Indicator
- Network Speed Simulation
- Frequency and Security Analysis

## Setup
1. Clone this repository.
2. Ensure you have Flutter installed.
3. Run `flutter pub get`.
4. Run `flutter run`.
